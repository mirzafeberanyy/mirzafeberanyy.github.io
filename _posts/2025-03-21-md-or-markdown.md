Penjelasan tentang Markdown (MD).

### A. Apa Itu Markdown

Markdown adalah bahasa markup ringan (lightweight markup language) yang digunakan untuk menulis teks dengan format yang bisa dengan mudah diubah menjadi HTML.

Markdown dirancang agar:
- Mudah ditulis dan dibaca manusia
- Tetap bisa dikonversi ke HTML dengan cepat
- Digunakan luas di GitHub, Jekyll, Hugo, GitLab, dll.

### B. Ekstensi File

Markdown biasanya disimpan dengan ekstensi:
- **.md**
- **.markdown**

Contoh: `README.md, index.md, about.md`

### C. Kegunaan Markdown

>| Platform       | Fungsi Markdown                          |
| :-------------- | :---------------------------------------- |
| *GitHub*     | README file, dokumentasi repositori      |
| *Jekyll*     | Menulis halaman dan post blog            |
| *Docs Web*   | Dokumentasi proyek teknis                |
| *CMS*        | Konten artikel di CMS berbasis static    |
| *Chat Tools*....... | Digunakan di Slack, Discord, Notion, dll |

### D. Dari Markdown Ke HTML

Markdown bisa dikompilasi secara otomatis menjadi HTML, terutama dalam:
- Jekyll: file .md akan diubah ke HTML saat dibuild
- GitHub: langsung dirender sebagai HTML dalam halaman repo

Contoh:
>markdown (`# Halo Dunia`) 

akan menjadi:
>html (`<h1>Halo Dunia</h1>`)

### E. Kesimpulan

>| Markdown                              | Keterangan                          |
| :------------------------------------- | :----------------------------------- |
| Ringan & mudah dibaca               | Format seperti teks biasa           |
| Bisa dikonversi ke HTML             | Cocok untuk dokumentasi             |
| Dipakai di banyak platform          | GitHub, Jekyll, Notion, GitLab      |
| Ideal untuk dokumentasi teknis      | README.md, blog, wiki               |
| Kurang cocok untuk styling kompleks...... | Gunakan HTML/CSS untuk layout rumit |
