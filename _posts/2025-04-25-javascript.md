Penjelasan tentang JavaScript.

### A. Apa Itu JavaScript

JavaScript (JS) adalah bahasa pemrograman tingkat tinggi yang digunakan untuk membuat halaman web menjadi interaktif dan dinamis.

Jika:
- HTML → struktur
- CSS → tampilan
- JavaScript → interaksi dan logika (fungsi, event, animasi, dll)

### B. Sejarah Singkat

>| Tahun | Peristiwa                                                         |
| :----- | :----------------------------------------------------------------- |
| 1995  | Diciptakan oleh Brendan Eich di Netscape                          |
| 1997  | Distandarkan oleh ECMA (menjadi ECMAScript)                       |
| 2009  | Node.js lahir (JavaScript bisa dijalankan di server)              |
| Kini.......  | JavaScript jadi fondasi pengembangan web modern (React, Vue, dll) |

### C. Fungsi Utama JavaScript

>| Fungsi                    | Contoh                                    |
| ------------------------- | ----------------------------------------- |
| Validasi Formulir         | Cek apakah input kosong atau tidak valid  |
| Manipulasi DOM            | Mengubah konten HTML secara dinamis       |
| Menangani Event           | Saat tombol diklik, saat mouse digerakkan |
| Interaksi Asinkron (AJAX).... | Mengambil data dari server tanpa reload   |
| Membuat Animasi           | Efek transisi, slideshow, popup           |
| Web Application           | Dipakai di React, Angular, Vue, dll       |

### D. Keunggulan JavaScript

>| Keunggulan                  | Penjelasan                      |
| :--------------------------- | :------------------------------- |
| Interaktif                | Membuat UI jadi responsif       |
| Real-time                 | Bisa fetch data tanpa reload    |
| Cross-platform            | Bisa jalan di browser mana pun  |
| Didukung banyak framework..... | React, Vue, Angular, dll        |
| Komunitas besar           | Banyak sumber belajar dan tools |

### E. Kekurangan

- Dapat dimatikan oleh pengguna (via browser settings)
- Rentan disalahgunakan jika tidak diamankan
- Tidak ideal untuk pengolahan data berat di sisi client

### F. Framework & Library JavaScript

>| Jenis             | Contoh                  | Fungsi                             |
| :----------------- | :----------------------- | :---------------------------------- |
| Library           | *jQuery*              | Mempermudah manipulasi DOM         |
| Framework UI      | *React, Vue, Angular*..... | Membangun antarmuka aplikasi       |
| Server-side       | *Node.js*             | Menjalankan JS di server           |
| Backend Framework..... | *Express.js*          | Framework backend berbasis Node.js |

### G. JavaScript Modern (ES6+)

Fitur terbaru JavaScript (ES6 ke atas) meliputi:
- let dan const (pengganti var)
- Arrow function () => {}
- Template string `Halo ${nama}`
- Class dan modul
- Promises dan async/await

### H. Kesimpulan

>| JavaScript                              | Ringkasan                       |
| :--------------------------------------- | :------------------------------- |
| Bahasa logika dan interaktif         | Digunakan di frontend & backend |
| Wajib dikuasai untuk web development...... | Bersama HTML & CSS              |
| Meningkatkan pengalaman pengguna      | Tanpa reload, lebih interaktif  |
| Mendukung berbagai tools modern      | Framework, library, API, dll    |
