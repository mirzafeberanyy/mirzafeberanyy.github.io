Penjelasan tentang Ruby dan Jekyll.

### A. Apa Itu Ruby

Ruby adalah bahasa pemrograman dinamis, open-source, dan berorientasi objek, dibuat oleh Yukihiro "Matz" Matsumoto dari Jepang pada tahun 1995.

### B. Ciri Utama Ruby

>| Ciri                      | Penjelasan                                      |
| ------------------------- | ----------------------------------------------- |
| *Clean syntax*          | Penulisan kode yang sederhana dan mudah dibaca  |
| *Object-Oriented*       | Segalanya adalah objek (termasuk angka, string) |
| *Fleksibel & ekspresif*.......... | Memungkinkan banyak cara menulis solusi         |
| *Cross-platform*        | Bisa dijalankan di Windows, Linux, macOS        |

### C. Ruby dan WEB

Ruby sering digunakan dalam pengembangan web melalui framework Ruby on Rails, tetapi dalam konteks web statis, Ruby digunakan untuk menjalankan Jekyll, yang merupakan generator web statis.

### D. Apa Itu Jekyll

Jekyll adalah static site generator (pembangkit situs statis) Dikembangkan oleh Tom Preston-Werner, pendiri GitHub. Yang dibangun menggunakan Ruby. Jekyll:
- Mengubah file teks (Markdown, HTML, dll)
- Menjadi situs web statis yang cepat dan ringan
- Ideal untuk blog, portofolio, dokumentasi, dll

### E. Cara Kerja Jekyll

Jekyll akan:
- Membaca semua file teks di dalam folder proyek (Markdown, HTML)
- Menggabungkannya dengan template dan layout
- Menghasilkan halaman HTML murni
- Siap untuk dipublikasikan (misalnya ke GitHub Pages)

### F. Fitur-Fitur Jekyll

>| Fitur                     | Penjelasan                                          |
| ------------------------- | --------------------------------------------------- |
| *Markdown support*      | Menulis konten dengan sintaks Markdown              |
| *Blog-ready*            | Folder `_posts/` langsung mengenali tanggal & judul |
| *Template layout*       | Layout HTML bisa digunakan ulang                    |
| *Konfigurasi fleksibel*............ | File `_config.yml` untuk atur site title, URL, dll  |
| *GitHub Pages ready*    | Bisa langsung dipasang ke GitHub Pages              |

### G. Manfaat Menggunakan Jekyll + Ruby

>| Manfaat                    | Penjelasan                                            |
| -------------------------- | ----------------------------------------------------- |
|  Mudah dipasang           | Cocok untuk GitHub                                     |
|  Bersih                   | Kode rapi, terorganisir                                |
|  Cepat                    | Hasil akhir adalah HTML statis, tidak ada database  Pages                              |
|  Cocok untuk dokumentasi...... | Banyak digunakan untuk dokumentasi proyek open-source |
|  Mudah dipelajari     | Hanya perlu paham HTML, Markdown, dan sedikit Ruby    |

### H. Kesimpulan

+ **Ruby** adalah bahasa pemrograman yang menjadi dasar dari Jekyll.
+ **Jekyll** adalah alat pembuat web statis berbasis Ruby, cocok untuk blog, portofolio, atau dokumentasi.
+ Dalam Workshop Web Dasar, Jekyll membantu mahasiswa membuat website profesional tanpa harus paham JavaScript atau PHP, dan langsung bisa dipasang ke GitHub Pages.
